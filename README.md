\# ЛЦТ 2026 — прогнозирование аварий



Веб-сервис для диспетчеров ОДС, который прогнозирует риски отказа датчиков и несанкционированного доступа в инженерных коллекторах.



\## Выбранные направления



\- Отказ датчика

\- Несанкционированный доступ



\## Цель проекта



Сервис принимает данные мониторинга в заданном формате, оценивает вероятность риска на горизонте не менее 24 часов и показывает результат на дашборде с картой объектов.



\## Структура проекта



\- `backend/` — API, база данных, фоновые задачи и серверная логика

\- `frontend/` — интерфейс диспетчера и карта рисков

\- `ml/` — обработка данных, обучение, валидация и инференс моделей

\- `docs/` — архитектура, решения команды и материалы презентации

\- `infra/` — Docker и настройки запуска

\- `tests/` — автоматические тесты



\## Правила безопасности



\- Не добавлять в Git исходные датасеты.

\- Не добавлять пароли, токены, API-ключи и файлы `.env`.

\- Не добавлять модели, содержащие чувствительные данные.

\- Для тестов использовать синтетические или обезличенные данные.



\## Рабочий процесс



Все изменения выполняются в отдельных ветках и попадают в `main` через Pull Request.
