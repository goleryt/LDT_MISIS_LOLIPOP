# LDT MISIS LOLIPOP — мониторинг и подготовка прогнозного контура

Веб-сервис диспетчера: карта, объекты, датчики, история наблюдений, фактические тревоги, события, заявки, импорт и уведомления.

**Реальная ML-модель пока не подключена.** Сервис не генерирует прогнозы, вероятности или risk_score. Для будущей модели подготовлены контракт, таблицы, журнал прогнозов, решения диспетчера и связь с заявками.

## Запуск

1. Скопировать backend/.env.example в backend/.env, заменить пароль БД.
2. Из корня: `docker compose --env-file backend/.env -f infra/compose.yaml up --build -d`.
3. Создать администратора: `docker compose --env-file backend/.env -f infra/compose.yaml exec backend python -m app.admin create-user admin --role admin`.
4. Открыть http://localhost:8080 и войти.

Нет встроенных пользователей/паролей. Для работы загрузить обезличенные справочники объектов и каналов, затем события.
Миграции применяются автоматически контейнером migrate. Не используйте create_all для обновления существующей БД.
