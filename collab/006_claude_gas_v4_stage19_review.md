## Обязательно (must-fix)

1. **`strict_crossing_features`, строка 182: `prior = low_idx[low_idx < i]` внутри цикла по пересечениям.**
   - Это O(n) на каждое пересечение, то есть O(n · k) на канал. На канале с ~10⁶ секунд и тысячами пересечений —
     миллиарды сравнений.
   - Замена: `k = int(np.searchsorted(low_idx, i)) - 1`, `rise = None if k < 0 else (t0 - times[low_idx[k]]) / 60e6`.
     Результат тот же, так как `low_idx` отсортирован.
2. **`gas_seconds_from_raw`, строки 137–138: `map_elements(ep.pseudo_key)` построчно** по всем газовым секундам.
   - Это Python-вызов с SHA-256 на каждую строку: десятки миллионов на полном архиве.
   - Замена: `ep.key_map(pl, ev["ch"].unique(), "d_channel_key")` и то же для `ид_объект`, затем join по `raw`.
     Именно так это сделано в `event_panel_v3.py` и `gas_predictor_v3.build_features`.
