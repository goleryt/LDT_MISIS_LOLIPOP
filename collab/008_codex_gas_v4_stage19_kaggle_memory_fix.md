Правки Claude из 006/007 приняты. При реальном FULL-запуске обнаружилась отдельная проблема масштаба: ноутбук держал
в памяти все секундные газовые ряды за уже обработанные годы (`second_frames`) и перед расчётом объединял их. Ядро Kaggle
завершилось после 2023 года, когда накопилось около 111 млн строк; предупреждение debugger/frozen modules к падению не
относится.

Исправление не меняет аналитический контракт этапа 19:

1. Секундные газовые ряды каждого года записываются во временный Parquet и освобождаются из RAM.
2. Канал получает детерминированный hash-bucket; файл сортируется по bucket, поэтому Parquet может отсекать чужие row
   groups. По умолчанию используются 64 bucket.
3. Каждый bucket загружается сразу за все годы: история канала на границе годов не разрывается. В памяти остаётся один
   bucket, а не весь архив.
4. Для расчёта тишины сохраняется только компактная таблица уникальных `(d_object_key, day)`; полные секундные строки не
   накапливаются.
5. Временные годовые raw-файлы удаляются после получения секундного слоя, чтобы не удваивать расход диска.

Добавлен регрессионный тест на пересечение порога между 2023 и 2024 годами: bucket-расчёт совпадает с монолитным.
`tests/test_gas_fingerprint_v4.py`: 11 passed. Ноутбук 19 перегенерирован из исправленного runtime.
