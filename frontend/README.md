# Frontend

React + TypeScript интерфейс диспетчера.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Переменная окружения:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Проверка

```powershell
npm.cmd run build
```

Карта реализована локальным SVG-компонентом и не использует Leaflet/OpenStreetMap или внешние тайлы.
