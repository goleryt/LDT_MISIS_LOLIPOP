# Frontend

React + TypeScript интерфейс диспетчера.

## Карта Москвы

Основной экран использует **авторскую SVG-схему Москвы** из `MoscowBaseMap.tsx`.
Она встроена в приложение: тайлы, внешняя картографическая служба и запросы
за подложкой не требуются. Реку, парки, кольца, районы и ориентиры нарисовали
для навигационного контекста. Это иллюстрация города, а не геодезическая карта.
Доступны перемещение, масштабирование, выбор объекта, подсказки и переход к
датчикам.

Цвета и формы интерфейса адаптированы по
[макету Figma](https://www.figma.com/design/FVhrjN51sKjOazKFov8T9w/Untitled?node-id=0-1):
фон `#F7F7F5`, поверхности `#FFFFFF`, текст `#18181B`, подписи `#71717A`,
границы `#E4E4E7`, основной синий `#3157D5`, тонкие контурные иконки.
Шрифт интерфейса Nunito включён локально с [лицензией OFL](src/assets/fonts/OFL-Nunito.txt). Темы: тёмная (по умолчанию) и бежевая, выбор в «Настройках»; сама карта остаётся светлой.

Геоданные объектов не будут предоставлены. Backend вычисляет **устойчивые
условные точки** внутри Москвы из `object_id`. Они не соответствуют реальным
адресам или зонам риска. Об этом сообщают метка на карте, подсказка и карточка
объекта. Статусы маркеров отражают последние события, не ML-прогноз.
Ограничения покрытия ТЗ перечислены в `../docs/MAP_TZ_COVERAGE_RU.md`.

## Запуск и проверка

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run build
```

Для API можно задать `VITE_API_BASE_URL=http://127.0.0.1:8000`. Вход выполняется через страницу входа (`/api/v1/auth/login`).
