# LDT Sensor Development Panel v2

Приватный обезличенный dataset для сравнения ML-моделей в Kaggle.

- Единица наблюдения: канал датчика за наблюдаемый день.
- Основная цель: `target_failure_state_onset_24h`.
- Признаки заканчиваются в конце дня D, D+1 — запас на реакцию, цель наблюдается в D+2.
- `Неисправен` и `Обесточен` — наблюдаемые прокси-состояния, а не подтверждённые физические отказы.
- Строки 2026 года исключены.
- Сырые `ид_канала_данных` и `ид_объект` исключены. `d_channel_key` и `d_object_key` созданы HMAC-SHA256 с одноразовым удалённым ключом.
- Исходные CSV не входят в dataset.

`panel_manifest_v2.json` содержит схему, период, число строк, контрольные суммы и размеры временных выборок. При несовпадении manifest/notebook запуск останавливается.
