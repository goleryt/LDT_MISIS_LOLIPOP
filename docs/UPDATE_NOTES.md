# Обновление проекта после полной ревизии

Этот файл описывает изменения, внесённые поверх состояния репозитория,
переданного в архиве `LDT_MISIS_LOLIPOP.zip`.
Основной вид карты теперь использует авторскую интерактивную SVG-схему Москвы.
Внешняя картографическая подложка и её зависимости удалены. Точки объектов
остаются условными и не соответствуют адресам.

## Что завершено

- Исправлена локальная SVG-карта: выбор маркера снова открывает объект,
  drag/pan и zoom не перехватывают клик по точке; hover-подсказка вынесена
  в отдельный слой.
- Карта переработана как локальная векторная схема; перемещение, масштаб,
  выбор объекта и подсказки не требуют стороннего картографического сервиса.
- Добавлена полноценная страница объектов с фильтрами, поиском и переходом
  к объекту на карте.
- Добавлен журнал событий с серверной фильтрацией, пагинацией и переходом
  к конкретному объекту/датчику.
- Добавлены профилактические заявки: таблица БД, миграция, REST API и
  frontend-страница создания/изменения статуса заявки.
- Из карточки датчика можно создать профилактическую заявку с заранее
  выбранными объектом и каналом.
- Добавлены индексы для запросов истории событий/последнего состояния.
- Ограничен размер загружаемого CSV и исправлена регистрация импортов.
- CORS и лимит загрузки вынесены в переменные окружения.
- Исправлен аудит точных дубликатов CSV.
- Добавлен CI для статических проверок frontend/backend.
- Обновлены README, документация, `.env.example` и описание структуры.
- Неиспользуемые Vite/React-заглушки и старые страницы удалены.

## ML

ML-часть намеренно не реализована и не подменена фиктивными значениями.
В текущей сортировке датчиков действует:

1. активная тревога;
2. время последнего события по убыванию;
3. `channel_id`.

После получения контракта модели между пунктами 1 и 2 должен появиться
`risk_score DESC`.

## Что выполнить после получения обновлённого исходника

### Backend

```powershell
cd backend
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload
```

Новые миграции:

- `6f8d2ab42c31_add_preventive_requests.py`;
- `7bb10cf49ac2_add_event_query_indexes.py`.

### Frontend

```powershell
cd frontend
npm.cmd install
npm.cmd run build
npm.cmd run dev
```

## Проверочный сценарий

1. Карта: hover, drag, колесо, `+/-`, «Показать все».
2. Клик по маркеру открывает карточку объекта.
3. Клик по датчику открывает отдельную карточку с историей/графиком.
4. «Тревоги» -> строка -> карта -> нужный объект и конкретный датчик.
5. «Объекты» -> строка -> карта -> нужный объект.
6. «Журнал событий» -> строка с известным объектом -> карта/датчик.
7. Карточка датчика -> «Создать профилактическую заявку» -> создание заявки.
8. «Заявки» -> изменение статуса, переход к объекту.
9. «Импорт данных» -> CSV, повторная загрузка того же файла.
