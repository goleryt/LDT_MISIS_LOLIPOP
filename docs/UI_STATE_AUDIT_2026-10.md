# Аудит состояний интерфейса — 16.10.2026

Проверка кода страниц и основных flows Chrome; это не утверждение о проверке
каждой комбинации темы, роли, масштаба и отказа. Общие HTTP-запросы имеют timeout,
API ошибки переводятся в понятные сообщения без backend detail.
Логи и ограничения — [приёмка](FINAL_ACCEPTANCE_2026-10.md).

| Экран | Loading | Empty | Error/retry | Success / фактическая проверка |
|---|---|---|---|---|
| Login / SessionGate | Вход/проверка сеанса, блокировка повтора | Форма без сеанса | role=alert, безопасный текст; повтор проверки | Login/logout в Chrome, expiry/401/CSRF на backend |
| Карта | «Загрузка объектов…» | Пояснение и ссылка на раздел импорта в тексте | Alert + кнопка повторной загрузки | Обычная карта и глубокая ссылка; отдельный тест 503 → recovery, loading → empty |
| Объекты | «Загрузка объектов...» | Понятный пустой список/результат фильтра | Отдельный error panel, обновление | Таблица, переход к объекту, компактный экран |
| Датчики/история | Загрузка датчиков/истории | Нет каналов/событий/числовой истории | Ошибка запроса, возможность сменить объект/датчик и повторить | Конкретный канал из карты/тревоги/уведомления, история, заявка |
| Тревоги | «Загрузка тревог...» | Нет текущих тревог/результата фильтра | Ошибка загрузки и обновление | Переход к конкретному объекту/каналу; цвета фактические |
| Журнал событий | «Загрузка событий…» | «События не найдены» | Валидация диапазона/ошибка загрузки | Список, фильтры и временной диапазон; API smoke |
| Прогнозы | role=status, загрузка списка | Отдельное сообщение; текущие тревоги вынесены в свой раздел | role=alert + retry; проверен принудительный 503 | Real frozen runtime → detail → decision → linked draft |
| Уведомления | Последовательный polling | «Непрочитанных уведомлений нет» | «Связь потеряна», следующий опрос восстанавливает данные | Индивидуальный read, sensor deep link, backend duplicate prevention |
| Заявки | «Загрузка заявок...»; блокировка изменения статуса | «Заявок пока нет» только при успешной загрузке | Ошибка/понятное состояние недоступного списка | Создание, in_progress/completed; draft save/confirm/history с feedback |
| Импорт | Загрузка registry; busy загрузки файла | Пустая история | Локальная проверка файла, ошибка импорта/registry | CSV/XLSX/JSON/XML в выборе; JSON success + duplicate в Chrome |
| Отчёты | «Формирование отчёта…», параметры заблокированы | Пустой отчёт с заголовком/метаданными | Без backend detail; после отказа кнопки снова доступны | PDF/XLSX download; отдельно 5050 входных заявок → 5000 строк с усечением |
| Настройки | Нет фоновой загрузки данных, busy при logout | Не применимо к локальным предпочтениям | Ошибка выхода отображается | Навигация и logout в Chrome; переключение темы по существующей архитектуре |

Исправлены: отсутствующее объяснение пустой карты, видимый прогресс экспорта,
выбор всех поддержанных форматов, безопасные ошибки, точные ссылки уведомлений,
контраст feedback заявки, общий экран восстановления React.
Удалены неиспользуемый OverviewPage и связанный одиночный health API-клиент.

Остаются ручными: все темы и роли на каждом экране, масштабы 125/150 %, длительный
offline/polling и нативный Яндекс.Браузер. Девять lint-предупреждений React effects
зафиксированы; они не являются ошибками сборки и не скрываются как PASS линтера без замечаний.
