   эксплуатационные SLA/RTO и мониторинг. Email/SMTP не подключён.
3. Натуральный прогон в Яндекс.Браузере: исполняемый файл на стенде отсутствует.
   В Playwright предусмотрен YANDEX_BROWSER_PATH; Chrome не выдаётся за Яндекс.
4. Публикация на площадке заказчика, окончательные материалы презентации и
   демонстрационные данные требуют согласованной площадки и реальных результатов.

TLS/reverse-proxy, RBAC/LDAP-адаптер, безопасные импорты и аудит сохранены из main;
их модульные проверки включены в suite. Эта приёмка не означает проверку реального
каталога AD, сертификатов заказчика или всех внешних систем.

## Запуск и вход

Следуйте README.md и RUNBOOK.md. Встроенного пароля администратора нет.
Создание пользователя выполняется интерактивно:

```sh
docker compose --env-file backend/.env -f infra/compose.yaml exec backend python -m app.admin create-user admin --role admin
docker compose --env-file backend/.env -f infra/compose.yaml exec backend python -m app.admin create-user dispatcher --role dispatcher
```

Рабочие пароли не передаются аргументом и не включены в архив. Тестовый стенд
данной проверки находится на http://127.0.0.1:18081; его синтетические данные
не предназначены для эксплуатации. Для ML необходима отдельная инструкция ML_INTEGRATION_RU.md.
