# Передача ML-ветки

> Исторический handoff ветки `ml-models`. Итоговая `main` включает утверждённый
> газовый бандл в `models/bundles/`; остальные модели и исходные данные в Git
> не добавлены. Актуальный запуск: [ML_INTEGRATION_RU](ML_INTEGRATION_RU.md).

Ветка `ml-models` содержит исходный код пайплайна, ноутбуки 01–04 и 06–12, тесты, инструкции и обезличенные **агрегированные** результаты в `ml/results/summary_v1.json`. Сырые журналы, Kaggle panel, построчные predictions, ZIP-архивы результатов и сериализованные модели в GitHub не загружаются. Их нужно передавать отдельно через разрешённый приватный канал.

## Текущее решение

- Итоговый scorecard 12 успешно построен в полном режиме: контракт `missing-target-router-3.0`, 579 735 строк, контрольная сумма Parquet совпала. Баллы разных целей не усредняются.
- Прямые proxy-модули доступа, пожара и доступности имеют `backend_candidate = false`. В scorecard их маршрутизируемый `score = null`, `decision_status = abstain`.
- Синтетические сценарии доступа и пожара имеют `backend_scenario_score_allowed = true`, но это только уровень доказательности E4 — совпадение с искусственно созданным сценарием, не вероятность реального инцидента.
- Синтетический сценарий затопления имеет `backend_scenario_score_allowed = false`: поддержка менее 1% объектов и насыщенный бюджет тревог. Он также должен воздерживаться от выдачи балла.
- `research_score` сохраняется для анализа, но backend **не должен** показывать или использовать его вместо `score = null`.
- Подтверждённых инцидентов, физических привязок и записей ремонта нет. Полное соответствие ТЗ не доказано. Это исследовательский демонстратор, не готовая инцидентная модель.

## Важные результаты

| Эксперимент | Вывод |
|---|---|
| 08 access proxy | `backend_candidate = false`: основной бюджет насыщен, преимущества нейросети по необходимым критериям нет. |
| 09 fire proxy | `backend_candidate = false`: недостаточно положительных примеров для надёжного выбора. |
| 10 access synthetic | Learned detector почти не переносится на исключённое семейство: recall 0,006 / 0,002. Выбран простой anomaly baseline. |
| 10 fire synthetic | Learned detector: held-out synthetic recall 0,506 / 0,534, но проходит ограничение нагрузки только во втором фолде. Не объявлять реальной пожарной моделью. |
| 10 flood synthetic | Поддержка 0,75% / 0,68%; показ scenario score запрещён. |
| 11 availability proxy | TCN PR-AUC 0,328 / 0,388 против cadence rule 0,208 / 0,240 на разрешённых метках, но label coverage около 52%, а около 89–90% TCN-тревог имеют неизвестный исход. Выбран cadence rule; `backend_candidate = false`. |

Полные цифры и хеши исходных локальных архивов приведены в `ml/results/summary_v1.json`. Метрики синтетических сценариев нельзя смешивать с PR-AUC реальных proxy-меток.
