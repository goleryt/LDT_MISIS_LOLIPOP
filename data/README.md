# Данные

Исходные CSV/XLSX не должны попадать в Git. Локально они могут храниться в `data/dataset/`, но эта папка игнорируется `.gitignore`.

Для демонстрации используйте только обезличенные или предоставленные организаторами наборы. Названия исходных полей сохраняются без переименования; производные поля используют префикс `d_`.
